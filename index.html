Full-stack team capstone — server-side/API owner. Same team (Cache Kings) as Nuovo Fresco Pipe Network. Deployed a containerized production stack (Docker Compose, nginx/gunicorn) on AWS EC2, with pytest + Playwright tests running in GitHub Actions CI (52 passing tests at final merge).

Systematic Debugging: Node.js/Express Race Condition | 2026

Individual assignment — evidence-first debugging exercise. Diagnosed a save/publish race condition in a Node.js/Express draft-editor API by building a deterministic HTTP test harness and instrumenting the server to reproduce the bug under controlled timing — captured 5/5 reproducible stale-publish failures in trace logs before applying a fix.
